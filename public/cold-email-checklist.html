Strategy

  • make campaign shell›

    Container in ClientForge / LeadTables for leads + exports.

    1. new shell, or duplicate most-similar past campaign
    2. set status = Draft
    3. name clearly
    4. save
  • write hypothesis›

    One primary hypothesis. Not a novel.

    1. open campaign → Edit → High-Level Strategy tab
    2. fill "Campaign Overview + Hypothesis One-Liner"
    3. note: change vs last campaign
    4. note: primary metric + what "good" looks like
    5. note: why this change should win
    6. note: next-step ideas if confirmed vs disproven
  • pick funnel parts (lead magnet, offer)›

    Concrete things funnel routes through.

    1. pick lead magnet
    2. pick introductory offer
    3. confirm flagship offer
    4. if reusing — confirm still apply, move on
    5. if new lead magnet — run Lead Magnet Master SOP
  • plan funnel flow›

    Positive reply → closed client. One-liner per transition.

    1. use Funnel Conversion Strategy Checklist
    2. write one-liner per transition point
    3. save in CF/LT Campaign Planner → Funnel Config tab
    "None" or "keep simple" is fine — must be deliberate, not accidental.
  • pick sequence structure›

    Structure only, no copy yet. Path A or Path B.

    1. Path A — swipe Themeplate Stack (handles structure + themeplate selection)
    2. Path B — build from scratch via Sequence Structure Cheat Sheet:
    3. · email count (initial + followups)
    4. · threading
    5. · delays
    6. · sending days/times
  • pick lead volume›

    Drives infra needs in next step.

    1. early loops — aim for ~200 campaign-ready leads
    2. otherwise — LeadTables Campaign Forecaster from desired calls/clients
    3. no source yet — pond exploration first
  • pick A/B variant count›

    List size determines meaningful variant count.

    1. <400 leads — 0 variants
    2. 400–500 — 2 variants, big angle differences
    3. 500–1,499 — 2 variants (sweet spot)
    4. 1,500–3,000 — up to 3 (A/B/C)
    5. 3,000+ — ~1 variant per 1,000 leads
    6. first campaign — skip is OK
    Multi-thread sequences: each thread's initial uses different angle. Followups must work regardless of which initial variant lead got.
  • check infra capacity›

    Followups + initials share daily quota — not simple division.

    1. run sending infrastructure calculator
    2. inputs: lead volume, sequence length + delays, target velocity
    3. short on accounts — buy now (warmup ~2–3 weeks)

Copy

  • review spam law›

    Decide compliance before drafting, not after.

    1. unsubscribe mechanism / inclusion
    2. physical address inclusion
    3. GDPR considerations
  • set ethics line›

    Keep copy defensibly true. No false depth-of-attention.

    1. decide perso ethics standard
    2. decide "I was just on your site..." style line policy
    3. unsure — read Personalization Ethics lesson, pick standard
    4. adjust themeplates accordingly
  • pick themeplates›

    Skip if Stack swiped — already chose. Else pick per slot.

    1. browse Themeplates Database (full templates)
    2. or Fragments Database (assemble parts)
    3. or Examples Database (real-world inspo)
    4. or adapt winning copy from past campaign
  • pick personalization level›

    Niche-generic → fully custom per-lead.

    1. pick personalization depth
    2. list available variables: {{first_name}}, {{company_name}}, {{website}}, custom columns
    3. save list — needed for writing + sender config
  • gather perso data›

    Only if approach needs data not yet gathered.

    1. circle back to deferred Lead Ingredients items
    2. complete Finalization Stage perso steps
  • write emails + followups›

    AI-assisted drafting per email slot.

    1. open fresh AI Cold Email Writer chat
    2. load CF/LT context via LLM Context Exporter (ICP, offer, LM, funnel, vars)
    3. paste themeplate AI prompt → generate draft
    4. review + edit (accuracy, tightness, voice)
    5. score against Cold Email Scorecard
    6. save in CF/LT Campaign → Copy tab
  • write A/B variants›

    Initial emails in new threads = highest leverage to test.

    1. duplicate baseline email per slot you're testing
    2. swap angle / hook / substantiation
    3. each thread initial → genuinely different angle
    4. followups — work regardless of which initial variant lead received
  • score copy›

    Catch obvious issues before placement testing.

    1. run AI Email Scorer on every email + variant
    2. or score manually via Cold Email Scorecard
    3. fix low scores
    4. re-score until happy
  • run deliverability check›

    Every-Time Checklist — mechanical rules Scorecard skips.

    1. spam keyword screen
    2. no links / attachments / images in pre-reply emails
    3. plain text formatting
    4. fix anything caught
    Spintax bits at bottom of checklist — skip for now, covered later.

Monitor

  • check metrics daily›

    Cold Email Campaign-Monitoring Cheat Sheet.

    1. bounce rate — pause + investigate if above threshold
    2. open rate (if tracking) — sudden drop = deliverability flag
    3. positive reply rate — compare vs benchmarks as volume builds
    4. account health — connected, sending, good health scores
    Really bad metrics — pause campaign while debugging. Use Performance Debugging Cheat Sheet.
  • handle replies›

    Always from sender's unified inbox — never personal inbox.

    1. positive — reply same day, send LM, advance funnel
    2. negative — gracious "thanks for letting me know"
    3. unsubscribe — mark in sender + add to LT blocklist
    4. see Reply-Handling Cheat Sheet for objections / pricing / referrals
  • nurture engaged leads›

    Engaged but not yet booked / not yet next funnel step.

    1. follow up on LM-received-but-quiet leads
    2. follow up on unbooked meetings
    3. close out dead leads gracefully
    4. early — keep manual / 1:1; later — automate via subsequences
  • loop back when done›

    Restart at top after final reply window.

    1. wait 3–4 days after last lead's final followup
    2. jump back to Close-Out Stage to post-mortem
    3. begin planning next campaign
